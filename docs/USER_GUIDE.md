## 系統需求與安裝

- Android 8.0（API 26）以上。
- 建議保留足夠儲存空間；5 分鐘錄影依畫面複雜度約需數十至數百 MB。

### 安裝 Pre-release APK

1. 從 GitHub Release 下載 `app-prerelease.apk`。
2. 在裝置上允許瀏覽器或檔案管理器「安裝未知來源的應用程式」。
3. 點擊 APK 完成安裝。
4. 此版本以 Debug 金鑰簽署，僅供測試，不適合正式上架。

### 從原始碼建置

```powershell
.\gradlew.bat assembleDebug
adb install -r app\build\outputs\apk\debug\app-debug.apk
```

## 首次啟動與權限

App 採「使用時才請求」原則：

| 權限 | 何時詢問 | 拒絕的影響 |
| --- | --- | --- |
| 通知（Android 13+） | 第一次按下「開始錄影」 | 仍可錄影，但不會收到錄影與儲存結果通知；可從 App 首頁停止 |
| 麥克風 | 開啟「麥克風錄音」並開始錄影時 | 可選擇「不錄音，繼續」只錄畫面，或取消本次錄影 |
| 螢幕擷取 | 每次開始錄影時由系統詢問 | 未同意則不會開始錄影 |

> 通知權限只會在第一次開始錄影時詢問一次；之後若需開啟，請至 Android 系統設定中的 App 通知頁面調整。

## 錄影流程

1. 在首頁確認「麥克風錄音」開關狀態（預設關閉）。
2. 點「開始錄影」。
3. 若設定頁選擇了倒數秒數，系統螢幕擷取同意後會先顯示倒數。
4. 倒數結束後開始錄影，首頁顯示計時器、進度條與「停止錄影」按鈕。
5. 達到 5 分鐘上限時會自動停止並儲存。
6. 儲存完成後會自動開啟該影片的預覽頁，並顯示「影片已儲存」。

### 倒數

- 可在設定頁選擇「無」、「3 秒」、「5 秒」或「10 秒」。
- 倒數期間點擊畫面、按「取消」或按系統返回鍵都會取消本次錄影。
- 倒數期間若離開 App，倒數會取消。

## 錄影中的操作

- **App 內停止**：首頁卡片上的「停止錄影」。
- **通知停止**：下拉通知欄，點「停止錄影」動作按鈕。
- **返回 App**：點通知本體回到 App。
- **剩餘時間提醒**：剩餘 30 秒時，首頁與通知會顯示提醒。
- **準備中停止**：顯示「正在準備錄影…」時仍可停止，不會產生成品。
- **中斷處理**：若系統停止螢幕擷取、鎖定螢幕或發生錯誤，會顯示對應訊息且不留下未完成檔案。

## 影片庫與播放

首頁「近期錄影」依錄影時間由新到舊排列，每列顯示：

- 影片縮圖（載入前顯示佔位圖示）
- 影片名稱
- 錄影日期與時間
- 影片長度

點選任一影片進入預覽頁：

- 播放器固定以 4:3 顯示框呈現；全螢幕時依裝置比例填滿。
- 播放中保持螢幕恆亮。
- 耳機拔出或其他 App 取得音訊焦點時會暫停。
- 點右上角全螢幕圖示進入全螢幕；按返回鍵或關閉圖示退出。
- 若影片損毀或無法解碼，顯示「無法播放這支影片」。

## 剪輯與另存副本

1. 在影片預覽頁按「剪輯」。
2. 拖曳範圍滑桿選擇保留的起點與終點。
3. 按「預覽片段」可先試看選取範圍。
4. 按「儲存副本」開始匯出，畫面顯示匯出進度。
5. 匯出期間可按「取消」中止；取消不會留下未完成檔案。
6. 完成後會自動開啟新副本，原始影片保持不變。

> 匯出採重新編碼，耗時依影片長度與裝置效能而異。

## 重新命名、分享與刪除

### 重新命名

- 名稱上限 80 個字元。
- 不可空白、不可開頭為點，且不可包含 `\ / : * ? " < > |`。
- 不可與現有影片同名。
- 對話框開啟時會自動全選名稱，鍵盤完成鍵可直接儲存。

### 分享

按「分享」會開啟 Android 系統分享面板，以 `video/mp4` 分享暫存 URI 給其他 App。目標 App 需支援接收影片。

### 刪除

按「刪除」後會跳出確認對話框；確認後即從裝置刪除，**無法復原**。

## 設定

點首頁右上角齒輪進入設定頁：

| 設定 | 說明 |
| --- | --- |
| 顯示模式 | 跟隨系統、淺色、深色 |
| 使用桌布動態色彩 | Android 12 以上才顯示；依系統桌布產生配色 |
| 錄影開始前倒數 | 無、3 秒、5 秒、10 秒 |
| 關於簡單錄影 | 顯示版本名稱、版本碼、授權與隱私說明 |

設定以 DataStore 儲存，重新啟動 App 後仍會保留。

## 檔案位置與備份

- 錄影存放於 App 私有目錄：`/data/user/0/com.vibecode.simplerecorder/files/recordings/`。
- 檔名預設為 `錄影_yyyyMMdd_HHmmss.mp4`。
- 未完成的暫存檔以 `pending-*.tmp` 命名，超過 24 小時會自動清除。
- App 關閉備份（`allowBackup="false"`），影片不會隨系統備份上傳。
- **解除安裝 App 會刪除所有錄影**，如需保留請先使用「分享」另存到其他 App 或雲端。

## 疑難排解

| 症狀 | 可能原因與處理方式 |
| --- | --- |
| 按下錄影後沒有反應 | 確認已在系統對話框允許螢幕擷取；確認未處於倒數狀態。 |
| 無法開始含麥克風的錄影 | 檢查麥克風是否被其他 App 占用，或至系統設定確認已允許錄音權限。 |
| 無法儲存影片 | 檢查可用儲存空間；避免開始後立即停止。 |
| 錄影中旋轉畫面後有黑邊 | 輸出尺寸於開錄時固定，屬預期行為。 |
| 沒有收到通知 | 通知權限未開啟或系統通知被封鎖；可從 App 首頁停止錄影。 |
| 播放沒有聲音 | 錄影時未開啟麥克風；或裝置音量／音訊輸出設定問題。 |
| 影片無法播放 | 檔案可能損毀或格式不受支援；可嘗試分享到其他播放器。 |
| 找不到舊錄影 | 確認未重新安裝或清除 App 資料；解除安裝會刪除私有目錄。 |

若問題持續，請附上 Android 版本、裝置型號與重現步驟，於 GitHub Issues 回報。

## 已知限制

- 每段錄影固定上限 5 分鐘。
- 不錄製 App 內部播放音訊。
- 輸出解析度於開錄時決定，錄影中改變視窗大小或旋轉可能留黑邊。
- 無法暫停後續錄，只能停止並另存一段。
- 影片僅存於 App 私有目錄，未整合系統相簿或 MediaStore。
- Pre-release 版本使用 Debug 金鑰簽署，不適合正式發布。
